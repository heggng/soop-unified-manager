# SOOP Unified Manager

SOOP 즐겨찾기와 구독 스트리머를 한 화면에서 확인하고 설정하는
웹 대시보드입니다.

**웹사이트:** https://soop-unified-manager.vercel.app

## 주요 기능

- 즐겨찾기와 구독 목록을 같은 웹 대시보드에서 전환
- 이름 검색 및 LIVE·고정·알림·즐겨찾기 상태 필터
- 알림, 즐겨찾기, 그룹, 구독 닉네임, 결제 정보, 상단 고정 설정
- 데스크톱과 모바일에 맞춘 반응형 카드 화면
- 로그인 정보와 스트리머 목록을 외부 서버에 저장하지 않는 로컬 연결

## 작동 방식

SOOP은 외부 웹사이트에서 로그인 세션이나 설정 API에 직접 접근하는 것을
허용하지 않습니다. 이 프로젝트는 Tampermonkey 사용자 스크립트 v1.2.0을
SOOP 페이지에 한 번 설치한 뒤, 이를 로컬 보안 브리지로 사용합니다.

1. 웹 대시보드에서 `SOOP 연결`을 누릅니다.
2. 로그인된 SOOP 보조 창이 열리고 목록을 대시보드에 전달합니다.
3. 대시보드의 설정 버튼은 보조 창의 SOOP 공식 UI를 실행합니다.

즐겨찾기·구독 목록과 계정 쿠키는 Vercel 서버에 전송하거나 저장하지
않습니다.

## 개발

Node.js 22 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

검증 빌드:

```bash
pnpm build
pnpm build:vercel
```

## 프로젝트 구성

- `app/`: 직접 관리형 웹 대시보드
- `public/downloads/`: 로컬 연결 브리지 사용자 스크립트
- `outputs/`: 로컬 작업용 원본 스크립트와 문서
- `vercel.json`: Vercel 배포 및 사용자 스크립트 응답 헤더 설정

## 주의

이 프로젝트는 비공식 사용자 프로젝트이며 SOOP Corp.와 제휴 또는 보증
관계가 없습니다. SOOP의 페이지 구조가 변경되면 로컬 브리지 업데이트가
필요할 수 있습니다.
