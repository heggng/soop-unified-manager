# SOOP 즐겨찾기·구독 통합 관리

즐겨찾기 페이지의 `스트리머 관리` 팝업 안에서 즐겨찾기와 구독
스트리머를 함께 관리하는 Tampermonkey 사용자 스크립트입니다.

> **중요:** `soop-favorite-manager.user.js` 파일을 Windows 탐색기에서
> 더블클릭하지 마세요. Windows Script Host로 실행하면 `800A03EA` 구문 오류가
> 표시됩니다. 이 파일은 Windows에서 직접 실행하는 프로그램이 아니라
> Tampermonkey 안에 등록해 사용하는 브라우저 스크립트입니다.

## 설치

1. 네이버 웨일에서 Tampermonkey 대시보드를 엽니다.
2. 기존 `SOOP 즐겨찾기 한눈에 관리`의 편집(연필) 버튼을 누릅니다.
   처음 설치하는 경우에는 `새 스크립트 만들기`를 누릅니다.
3. Windows 탐색기에서 `soop-favorite-manager.user.js`를 마우스 오른쪽
   버튼으로 누르고 `연결 프로그램` → `메모장`을 선택합니다.
4. 메모장에서 `Ctrl+A`, `Ctrl+C`를 눌러 전체 내용을 복사합니다.
5. Tampermonkey 편집기의 기본 내용을 모두 지우고 `Ctrl+V`로 붙여넣습니다.
6. `Ctrl+S`로 저장합니다.
7. `https://www.sooplive.com/my/favorite` 페이지를 새로고침합니다.

Tampermonkey 목록에서 이름이 `SOOP 즐겨찾기·구독 통합 관리`, 버전이
`1.1.0`으로 표시되면 업데이트가 완료된 것입니다.

## 사용

- 페이지 **상단 오른쪽**의 `★ 즐겨찾기·구독 관리` 버튼이나 SOOP의 기존
  `스트리머 관리` 버튼을 누릅니다.
- 관리 창 위쪽의 `즐겨찾기`와 `구독` 탭으로 같은 창에서 목록을 전환합니다.
- 즐겨찾기 탭에서는 `전체`, `LIVE`, `고정`, `알림 켜짐`, `알림 꺼짐`
  필터와 알림·즐겨찾기·그룹·고정 설정을 사용할 수 있습니다.
- 구독 탭에서는 `전체`, `LIVE`, `고정`, `즐겨찾기`, `미즐겨찾기` 필터와
  즐겨찾기·구독 닉네임·결제 정보·고정 설정을 사용할 수 있습니다.
- `구독·결제 내역 ↗`을 누르면 상세 구독/결제 내역 페이지가 열립니다.
- `↔ 여유 있게` 또는 `↔ 촘촘하게`를 눌러 카드 밀도를 바꿀 수 있습니다.
  선택한 밀도는 브라우저에 저장됩니다.
- SOOP의 기존 검색, 전체 알림, 고정 숨기기, 정렬 기능도 그대로
  사용할 수 있습니다.

## 동작 방식과 주의사항

- 구독 목록은 같은 로그인 세션의 SOOP `/my/subscribe` 페이지에서
  불러옵니다. 별도의 외부 서버로 정보를 전송하지 않습니다.
- 설정 변경은 SOOP 페이지에 이미 있는 공식 버튼과 메뉴를 호출합니다.
- 구독 닉네임 또는 결제 정보를 누르면 SOOP 원본 입력 창이 앞으로
  표시됩니다. 설정을 마친 뒤 위쪽의
  `설정을 마치고 통합 관리로 돌아가기`를 누르세요.
- `즐겨찾기 해제`는 SOOP의 원래 동작처럼 해당 스트리머를 목록에서 즉시
  제거하므로 버튼 이름을 확인한 뒤 누르세요.
- SOOP이 관리 창의 구조나 클래스 이름을 크게 변경하면 스크립트 업데이트가
  필요할 수 있습니다.
